# Use Case: Request Directory

**Context:** At any time, a ChocAn provider can request the Provider Directory. The Provider Directory contains an alphabetically ordered list of service names with their corresponding service codes and fees. 

**Actors:** Provider

**Main Success Scenario:**
1. The provider requests the Provider Directory.
2. The system retrieves the current list of ChocAn services.
3. The system sorts the services alphabetically by service name.
4. The system includes the service name, service code, and fee for each service.
5. The system creates the Provider Directory file for the provider

**Extensions:** N/A
