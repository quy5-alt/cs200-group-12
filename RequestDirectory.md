# Use Case: Request Directory

**Context:** At any time, a provider can request the Provider Directory, which contains an alphabetically ordered list of service names and their corresponding service codes and fees.

**Actors:** Provider

**Main Success Scenario:**

1. The provider requests the Provider Directory.
2. The system retrieves the list of available services.
3. The system lists the service names in alphabetical order with their corresponding service codes and fees.
4. The system sends the Provider Directory to the provider as an email attachment.
